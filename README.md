# 🌙 Projeto Restaurante Café Lunar (MenuZap)

## 📄 Descrição
O **Projeto Restaurante Café Lunar** é um cardápio digital interativo desenvolvido para facilitar a visualização de produtos e itens do menu de um restaurante ou café. O projeto simula a interface de um aplicativo de pedidos (MenuZap), oferecendo uma experiência simples e direta para o usuário conferir as opções disponíveis.

## 🚀 Funcionalidades
- Visualização do cardápio digital.
- Estrutura leve e de rápido carregamento.
- Interface baseada no MenuZap.

## 🛠️ Tecnologias Utilizadas
Este projeto foi desenvolvido utilizando:
- **[HTML5](https://github.com/FernandoG411/Projeto-Restaurante-Cafe-Lunar/search?l=html)** - Estruturação de todo o conteúdo da página web.
